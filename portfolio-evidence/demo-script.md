# 3–5 分钟离线 Demo 讲稿

## 演示前准备

```bash
./stop-demo.sh
./reset-demo.sh
./run-demo.sh
```

打开 <http://127.0.0.1:5280/decision/market-replay>。录屏脚本使用全新的隔离浏览器上下文，不读取个人浏览器数据；在任何写请求前，还会验证 Backend 同时启用了 fixture 和项目内 `.demo-storage`。

## 讲述路径

| 时间 | 操作 | 要证明的工程事实 |
| --- | --- | --- |
| 0:00–0:22 | 展示首屏和“离线合成数据”，选择 20 交易日 | Demo 不依赖实时行情或个人数据 |
| 0:22–0:48 | 创建场景，填写一笔 25% 买入决策 | Web 调用真实 Backend，决策依据与风险边界随订单冻结 |
| 0:48–1:10 | 推进一天 | 委托在下一开盘执行，成交事件和费用进入账本 |
| 1:10–1:32 | 提前交卷并打开盲评 | 会话状态转换由 Backend 统一约束，持仓按当前价估值 |
| 1:32–1:58 | 保存揭晓前盲评 | 身份和未来行情继续隐藏；原始盲评保存后不可覆盖 |
| 1:58–2:10 | 揭晓答案 | 同一会话恢复真实日期、标的身份和完整行情 |
| 2:10–2:38 | 保存事后复盘和调整建议 | 评分与复盘进入可追溯账本，建议不会直接改规则 |
| 2:38–2:51 | 历史演练生成候选 | 逐笔成交、评分、盲评和复盘可追溯 |
| 2:51–3:02 | 战法库人工采纳并展示 v2 | 只有人工确认后才创建不可变的新版本 |

## 推荐讲述句

“我把外部行情放在可替换 seam 后面。现场演示使用确定性的 synthetic adapter，但订单、成交、复盘和 SQLite 持久化没有 mock。失败状态也不靠临时断网碰运气，而是由结构化错误契约和自动化测试固定。AI Coding 负责大量实现，我负责规则、任务拆解、接口取舍和最终验收。”

## 录制命令

服务启动后运行：

```bash
node scripts/record-portfolio-demo.mjs
```

输出为 `portfolio-evidence/video/InvestFlow-Replay-offline-demo.mp4`。脚本只操作 `.demo-storage` 对应的本地 Demo 服务。
