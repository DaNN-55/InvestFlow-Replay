## 给试用者的介绍

InvestFlow Replay 是一个本地运行的交易演练工具。隐藏标的身份与后续走势，逐步做出模拟买卖决定，再揭晓、复盘和回看历史记录。

这一版提供：

- 独立存储的离线合成行情 Demo，支持 20 / 60 / 120 日日线演练。
- 通达信真实行情日线与 5 分钟日内模拟。
- 模拟买卖、盲评、揭晓、事后复盘与会话恢复。
- 独立静态展示页与 Apache-2.0 许可证。

从仓库 README 安装后，推荐先运行 `./run-demo.sh` 完成一次离线演练，再运行 `./run.sh` 体验真实行情。依赖安装需要网络；“离线”指 Demo 运行不连接行情服务。
