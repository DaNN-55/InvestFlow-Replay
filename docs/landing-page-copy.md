# 把交易判断留在未知行情里

InvestFlow Replay 把一段历史行情冻结成你尚不知道结果的训练场。你在可见行情中做模拟决策，盲评先冻结，揭晓后再复盘；判断、订单与记录都留在本机。

主按钮：[先看新手练习步骤](#offline-demo)

次按钮：[查看真实行情要求](#real-market)

首屏背景演示：一组红涨绿跌、低对比度的示意 K 线横跨整个 Hero。桌面端鼠标进入后，竖直揭晓边界跟随横向移动，边界右侧的行情由浅色遮罩完全覆盖；鼠标离开后回到默认位置。标题、说明和按钮始终位于背景上层。触屏设备和系统开启“减少动态效果”时使用固定遮罩位置。

首屏档案条目：

- 未知行情训练：不是回测结果展示。
- 可追溯产物：决策、模拟订单、盲评与复盘。
- 本地边界：不连接证券账户，不真实下单。

## 怎么开始：第一次使用，先选左边

先用系统自带的示例数据熟悉整个流程。等你确认会用了，再切换到真实历史行情。两种方式都在你的电脑上运行。

### 先用示例数据练一遍

安装完成后运行 `./run-demo.sh`，就能直接开始练习，不需要另外准备行情数据。

- 练习数据由系统生成，不代表真实市场。
- 启动后不会联网获取行情，练习记录单独保存在 `.demo-storage/`。
- 可以完整体验模拟买卖、逐步查看后续行情、先写判断再看结果，以及最后复盘。

说明：安装项目时仍需联网下载依赖；开始练习后不连接行情服务。

入口：[查看新手练习步骤](https://github.com/DaNN-55/InvestFlow-Replay#离线演示)

### 再用真实历史行情练习

想用真实历史数据练习时，运行 `./run.sh`。程序会先在电脑上准备行情数据，再进入日线或 5 分钟练习。

- 第一次使用需要联网准备和更新行情数据。
- 电脑需要安装 Python 3.10–3.13 和 Node.js 22+。
- 部分股票或时间段可能因为数据源暂时不可用而无法练习。

说明：建议先完成一次示例数据练习，再使用真实历史行情。

入口：[查看真实行情安装说明](https://github.com/DaNN-55/InvestFlow-Replay#快速开始)

### 安装并启动

该区块默认折叠。

- 折叠标题：安装并启动
- 折叠说明：准备在本机使用时，展开查看三步命令。
- 折叠图标：收起时显示无边框的 `+`，展开时显示 `−`。

展开后提示：打开“终端”，依次完成下面三步。第一次使用建议先启动示例数据。

1. 下载项目

   ```bash
   git clone https://github.com/DaNN-55/InvestFlow-Replay.git
   cd InvestFlow-Replay
   ```

2. 安装依赖

   ```bash
   ./install.sh
   ```

3. 选择启动方式

   ```bash
   # 示例数据（推荐）
   ./run-demo.sh

   # 真实历史行情
   ./run.sh
   ```

每一步使用命令与复制操作同排的一体式代码框。第三步的两种启动方式合并在同一代码框内，用注释区分并共用一个复制图标。复制成功后图标短暂切换为勾选状态，同时向辅助技术播报结果。

- 示例练习地址：`http://127.0.0.1:5280/decision/market-replay`
- 真实行情地址：`http://127.0.0.1:5180/decision/market-replay`
- 停止服务：示例数据运行 `./stop-demo.sh`；真实行情运行 `./stop.sh`。

## 一次演练留下什么

它留下的是一次在有限信息下的训练记录，而不是对战法有效性的自动证明。

1. 当时的判断：会话里的盲评记录你对行情、计划与风险的原始判断；可引用有明确版本号的战法版本。
2. 模拟订单与成交：模拟买卖、订单事件和账户变化与本次会话关联，供你回看执行过程。
3. 冻结盲评：揭晓前的盲评会冻结；后续补充以修正记录追加，不替换原始内容。
4. 事后复盘：揭晓后基于完整结果保存事后复盘，与原始判断并列保留。
5. 历史演练记录：已完成会话可在历史演练中回看，训练档案和行情缓存均保存在本机存储中。

## 适用范围与边界

### 适合谁

了解基本 K 线与买卖概念，愿意在本机安装、完成一次训练闭环，并反馈哪里难以理解或无法继续的个人学习者。

### 暂不适合谁

期待免安装在线交易或收益结论的人。这里没有公开的多人在线体验、账号云同步或证券账户连接；模拟结果不能代表真实收益，也不自动证明战法版本有效。

### 本地存储与数据

- 正式运行时，`storage/app/` 保存演练、订单、复盘与战法账本，`storage/market/` 保存行情缓存。
- 离线 Demo 使用独立的 `.demo-storage/`。
- 真实历史行情的覆盖与稳定性依赖外部数据源和本地缓存，部分证券或时段可能不可用。

### 版本、平台与许可

- 版本：v0.1.0-alpha.1
- 平台：仅 macOS 已完成本地验收；其他系统待验证。
- 许可：Apache-2.0
- 行为边界：不连接证券账户，不真实下单，不承诺收益。

## FAQ

### 这是免安装的在线体验吗？

不是。展示页不调用行情 API；两条训练路径都需要下载项目并在本机安装运行。主入口先带你看离线 Demo 的实际步骤。

### “离线”是不是完全不需要网络？

不是。安装依赖需要网络；离线指 `./run-demo.sh` 启动后的 Demo 不连接通达信行情服务，并使用确定性的合成数据。

### 一次演练结果能证明战法版本有效吗？

不能。一次演练只留下一个受限信息下的训练记录；模拟成交与真实交易有差异，本工具不承诺收益，也不自动证明战法版本有效。
