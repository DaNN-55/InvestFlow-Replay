### 三处需要保留的口径差异

1. **剩余款**：FAQ 和合约强平说明描述全部保证金损失；较新的英文逐仓规则末尾允许有余额时返还。末段未分清哪些产品、部分减仓或全部接管情形。不能仅以更新时间推定其已推翻其他页面，也不能把“若有剩余”解读成每次必返。
2. **穿仓**：FAQ 表述为负余额由风险准备金代偿；强平制度保留平台裁量且不作赔付保证。教学方案可以自行规定不向仓外追扣，但必须标为模型边界，不能宣传为用户实盘的无条件保证。
3. **降档起点**：较新的逐仓永续规则写二档及以上分档处理，旧合约 FAQ 写三档及以上。首版已选择统一全额接管，须显式承认简化；以后模拟部分减仓，应以适用的专门规则和新版本重新核对。

减仓费的存在和与档位的关系已有依据；仍缺本范围完整接管账单示例，无法锁定每笔收费取价、舍入、分次减仓分摊及返还条件。当前 `liquidationClearanceFeeRate=null` 表示**未闭合的精确数值模型**，不表示没有这类成本，也不表示一个固定费率只等查询。

## 已确认的教学结算

### 接管前的处理

沿用已核对的 mark 风险公式和冻结档位。时间精度最低 1m；能确定开盘已越线时使用开盘 mark；仅能确认分钟内越线时记录分钟区间和歧义，不能伪造精确秒级时间。

撤销该仓相关挂单、释放委托冻结，重新检查风险；若已恢复安全，不执行接管。如果仍不安全，该版本统一全额接管，不保留部分仓位。已知更早完成的平仓或追加按既定事件顺序先入账；接管完成后不能用本分钟稍后的操作追溯挽救。

### 一次结算，费用不再叠扣

定义：

- `F`：撤单释放冻结后、该仓以外的 USDT 现金余额。
- `M`：接管前该仓实际保证金账面余额，含已入账的手动追加、资金费收付和此前减仓影响；不把浮亏再扣进 `M`。
- `U`：所选参考 mark 下的未实现盈亏。

正常 `M >= 0` 时，模型结果为：仓位数量归零、该仓保证金归零、不返还保证金、仓外现金保持 `F`。从账面现金角度，该仓本次合计结算损益为 `-M`。

**此前开仓手续费、资金费和已平部分损益仍保留原有记录，本次不重复扣。** 强平手续费和可能的减仓成本包含在该次合计损失内，不能先清零 `M`，又从 `F` 扣 taker、MMR 或 2 bps 滑点费。

若资金费原子结算令 `M < 0` 后立即触发接管，教学模型将负余额核销并明确列“教学欠款豁免”，不向 `F` 追扣；核销不是交易盈利。资金费的应计金额仍保留，不能静默截断到零。

### 成本解释桥接，只作说明

为说明“浮亏之外还失去了什么”，保存以下参考分解，**不再作为第二组入账项目**：

```text
T = round8(q × P_ref × takerRate)   # 参考强平手续费，非已知实际账单
B = M + U - T
W = max(B, 0)                     # 教学剩余权益扣除
S = max(-B, 0)                    # 教学缺口豁免
U - T - W + S = -M
```

`q` 为标的币数量，`P_ref` 为参考 mark。连续越线可用阈值向不利价格步长取整：多头向下、空头向上；已知跳空则用观测到的开盘 mark，不强行改回阈值。参考价、阈值和行情来源分别存储，`actualLiquidationFillPrice` 保留未知。

`W` 不是“官方 clearance”或“实际注入风险准备金”；`S` 不是对 OKX 保险付款的预测。`T` 只按固定训练 taker 率展示参考金额，普通 2/10 bps 成交滑点不再套在本次合计损失之上。实际强平费用拆分仍保留未知。

账本只记一次合计接管事件；报告可展示桥接，但不得把桥接与合计相加。净收益按该教学版本计算并标识，精确手续费统计不能把参考拆分当实测费用。接管前若总权益已含 `U`，本事件权益变化为 `-(M+U)`，不是再下降 `M`；遇穿仓时变化可能为正，须同时展示豁免，不能计作获利。

## 可复核算例

统一假设 BTC 10 张 = 0.1 BTC，开仓成交价 50,000，5 倍，初始划入 1,000，已付开仓费 2.5；初始账户 10,000；一档 MMR 0.004，taker 0.0005。这些是给定输入，不将模拟参考价冒充真实成交。

| 场景 | 接管前 M / 参考 mark | U / 参考手续费 T | W / S | 最终仓外现金 |
| --- | --- | --- | --- | --- |
| 基础多仓越线 | 1,000 / 40,180.8 | -981.92 / 2.00904000 | 16.07096000 / 0 | 8,997.5 |
| 手动追加 500，随后已付资金费 5 | 1,495 / 35,208.4 | -1,479.16 / 1.76042000 | 14.07958000 / 0 | 8,497.5 |
| 多仓开盘跳空穿仓 | 1,000 / 30,000 | -2,000 / 1.50000000 | 0 / 1,001.50000000 | 8,997.5 |
| 空仓越线 | 1,000 / 59,731.3 | -973.13 / 2.98656500 | 23.88343500 / 0 | 8,997.5 |

基础例累计损失 1,002.5，其中开仓费已付 2.5、接管结算 1,000；不能再扣 981.92 浮亏或一笔强平费。到达接管点时总权益已为 9,015.58，接管使其再减少 18.08，而非再次减少 1,000。

追加例累计损失 1,502.5 = 开仓费 2.5 + 已付资金费 5 + 本次结算 1,495；不能写成 1,507.5。仅在保证金未被消耗且平仓释放时，追加属于内部转账；追加后的钱在强平中同样承担损失。

跳空例中的 1,001.5 是参考分解的缺口豁免，包含参考手续费；它不是从某个实盘保险池读取的赔款。

[已确认口径的 Decimal 数值证据](./okx-rule-snapshots/2026-10-19-liquidation-teaching-cases.json)包含上述 BTC 场景、恰好 100%、资金费导致负保证金，以及 ETH 多空场景，共 8 例。ETH 例均为 10 张 = 1 ETH，开仓价 3,000、初始保证金 600、开仓费 1.5；多仓参考 mark 2,410.84，空仓 3,583.88，两者结算后现金均为 9,398.5。这只是独立算术检查，未运行或验证业务引擎。

[原提案的 6 例证据](./okx-rule-snapshots/2026-10-19-liquidation-teaching-cases.proposed.json)保留为历史过程记录；后续实施以正式版本及其 8 例为准，不把原文件的 Proposed 状态当成当前决定。

## 与实盘的差异

| 项目 | 已确认教学模型 | OKX 实盘/公开资料 |
| --- | --- | --- |
| 接管范围 | 复核不安全即一次全平 | 有撤单、逐档部分减仓及全平，可能保留仓位 |
| 接管后余额 | 该仓不返还 | 资料既有全部损失，也有余额存在时返还的表述 |
| 接管价格 | mark 仅作风险和解释参考，不生成真实成交价 | 接管后引擎另行委托并撮合，价格不等同于触发 mark |
| 成本明细 | 合计结算确定；手续费为参考拆分，余项明确为教学调整 | 实际账单及引擎结算决定明细，不能从分钟线精确推回 |
| 穿仓追扣 | 教学模型明确不动仓外现金，缺口列豁免 | 普通说明与准备金裁量条款不能构成无条件保证 |
| 时间和事件顺序 | 1m 数据与冻结因果约定 | 连续行情、盘口、延迟、部分成交及风控介入 |
| ADL 等极端流程 | 不模拟盈利对手方被 ADL 的风险 | 实盘存在此类处理，不能凭本模型排除 |

“保守”只指对本仓返还和保留仓位采取更严厉结果；不能把整个模型称为所有实盘风险的最坏上界。它适合训练及时控制风险，也会影响强平后的净收益比较，因此同一次练习与复练必须冻结同一版本。
