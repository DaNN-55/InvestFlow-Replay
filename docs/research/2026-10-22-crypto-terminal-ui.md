## 成交量与合约工作区收紧

- 成交量问题复现：当前已展示的600根真实成交数据均有量，标记价格图却为0。原因是mark数据按契约不含成交量，前端把缺失量补成0。
- 两类价格图统一展示同周期、相同startMinute/knownThroughMinute的实际成交量（张），不修改原始mark数据；不匹配时隐藏量窗，绝不从后续分钟借量或把未知当零。
- 精简量窗时同时清除VOL均线参数/图形，并保留原A股默认值。真实图表库回归先复现空结果，再确认30根全部有量柱结果；图表实测可见量柱。
- 合约时间改为D1/-1D及小时分钟；主图OHLC随十字线显示，移除无数据涨幅及重复量值。图下加载数量、范围、形成中说明和重复进度行删除，回到当前移入工具栏。A股保留原状态栏和图表提示。
- 回放控制移至右侧下单卡片上方；原灰条是进度条，现在显示名称及百分比。收起下单时控制保留在图上方，小屏位于行情与下单之间。
- 交易动作列表移除280px内部限高与滚动，完整内容随页面滚动；原整体收起功能保留。
- 验证：前端单测220项；A股图表及交易详情浏览器回归21项，成交量真实渲染专项1项通过。正式练习仅只读恢复与切换显示偏好，无测试推进/下单。
- 1543px桌面及390px小屏核对右侧布局、控制保留、真实量柱和无横向溢出。后端执行、数据池及冻结版本不变。

## 自动回放倍率与多图因果边界复核

| 可检查结果 | 实现与证据 |
| --- | --- |
| 可调整播放速度 | 播放按钮旁提供1×/2×/4×/8×，浏览器记忆；倍率缩短请求完成后的等待间隔，不增加每次推进的1分钟步长。实际速度仍受同步耗时影响 |
| 暂停与事件不漏停 | 不并发推进；请求处理中仍可暂停，已发出的动作完成后不再排队；用播放代次排除旧循环重启。成交、保护成交、委托拒绝、资金费、风险及结束事件后暂停 |
| 跨周期旧柱正确补齐 | 真实原生图表复现：第6分钟推进15分钟后，旧15分钟柱停留在第6分钟。原分类器仅比较柱身份，误判纯追加；现先更新旧尾柱OHLCV再追加新柱，历史其他柱改变则完整替换 |
| 多图与未来数据隔离 | 临时数据库、真实后端、原生四图；遍历全部11种周期，逐根对照服务端因果前缀及量柱结果。十字线按回放分钟双向映射，越过已加载区间清除，不夹到末柱；不同价格类型不复制水平价线，关闭联动后不传播 |
| 仅当前已知分钟可见 | 合成数据在未来时点设置明显价格跳变；切换周期、1/5/15分钟推进、刷新均无提前显示。额外验证服务端拒绝越界游标；既有各周期未来OHLCV/资金费扰动不影响当前前缀测试通过 |

验证：前端222项、相关后端67项、浏览器9项通过（新增4项多图/倍率，成交量1项，A股共享图表4项）。新增用例进一步检查全部量柱数值后4项重跑通过。构建、限定文件ESLint及差异检查通过。1543px桌面与390px小屏只读恢复核对，正式练习未用于推进或下单测试。

下单流程保持：方向/市价或限价/数量→预览→提交→推进后撮合。理由与保护按需展开；风险预算需退出价，手动计划不自动执行，USDT数量单位表示名义金额。未扩大订单执行或数据池范围。
