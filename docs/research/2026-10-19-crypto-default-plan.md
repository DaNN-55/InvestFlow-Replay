## 从开始到结束

1. 从「行情演练 → 加密合约」开始新会话、继续或复练。新会话只显示必要预设，其余设置折叠。
2. 看到未知未来的历史行情，选择观察周期。可以直接等、记录简短想法或不做；参考战法可选。
3. 决定开多/开空时，可直接输入张数/保证金，也可输入计划退出价和风险预算估算仓位。金额按合约规格取整，同时预览数量、占用和成本。
4. 提交并推进。可加仓、减仓、平仓、撤单、管理止盈止损，或手动追加保证金。每次动作保存前后状态，金额与估算强平位置同步更新。
5. 模拟强平时暂停，显示触发依据、价格序列、保证金、费用和结算；若剩余资金和规则允许，可继续此会话，也可结束。强平本身不自动结束整份练习。
6. 提前结束或到达窗口末尾时先处理未平仓和剩余委托，再揭晓与复盘。结束结算单独标记，不当作用户原计划的主动退出。
7. 首次判断和结果保留，复练新建独立记录，起始配置与首次一致；改过规则/资金的练习不能不加区分地并入原条件对照。

## 下单、保护单与风险显示

### 已确认首期订单范围

- 市价开仓/平仓、限价开仓/平仓、撤单、同向加仓、部分平仓与全部平仓。
- 自动止损/止盈先采用「触发后市价退出」，两者都可选；平仓仅减仓，不能意外越过零反向开仓。
- 自动止盈止损默认参考最新成交价，提供标记价格选项；这是订单设置，与强平参考标记价格分别展示。指数价触发、止损限价和复杂跟踪止损后做，以免首期再引入额外价格流和执行分支。
- 同时设置止盈止损时，一边退出后取消另一边；减仓后剩余保护数量同步缩小；全部平仓后清理失效保护。
- 撤单只取消未成交部分；撤掉自动止损不会平仓。手动计划线与真实保护单使用不同状态和外观。
- 允许手动追加逐仓保证金；首期不自动补，也不把保证金转出/任意持仓中修改杠杆默认为必做。

### 三种退出状态

| 状态 | 呈现 |
| --- | --- |
| 自动止损已挂单 | 显示触发参考价、触发价和估算损失；实际成交可能偏离 |
| 仅有手动退出计划 | 计划线和条件性损失估算，明确需用户手动执行 |
| 没有明确退出价 | 退出损失显示「未定义」，不显示 0；仍可下单 |

三种状态均显示张数、对应币数、名义仓位、逐仓保证金、浮动盈亏（USDT 和占账户权益比例）、标记价格、估算强平价和距离。保证金不是手续费，也不冒充计划最大损失。

手动追加时显示从可用余额转入多少、转入后该仓保证金和估算强平位置。持仓数量保持不变，账户权益不会因内部划转增加，既有浮亏仍存在。

不预填一个必须使用的风险比例；风险预算辅助工具只有在用户提供明确计划退出价时才倒推仓位。调整杠杆/保证金/数量时标明哪个量保持不变，不暗中改变仓位。

## 执行、成本和规则版本的默认口径

- 市价单按提交后下一可执行分钟的开盘价加方向性滑点模拟；不回填用户已看到的收盘价。
- 限价单按预先冻结的分钟成交模型处理，价格触及不表示真实盘口必然轮到成交；不声称还原排队、冲击或真实全部成交。
- 止损/止盈触发后按模拟可执行价格处理，触发价不保证等于成交价。只用分钟 OHLC 无法确定路径时标记歧义，按冻结的保守口径给模拟结果，并在执行统计中单列。
- 强平依据独立 mark 价格流和冻结档位触发；先撤单复核，仍不安全则按已确认教学模型全额接管。当前该仓保证金（含追加和资金费影响）不返还；合计结算一次，参考手续费/教学调整只用于解释，不重复扣款，也不生成假的实际清算成交价。分钟内顺序仍可能不确定，不能声称精确还原实盘清算。
- 保留历史实际资金费事件，发生时入账；提前只显示当时已知信息，不把最终费率泄露给用户。合约规格、保证金档位、手续费及模拟结算口径采用明确的固定训练版本。
- 普通手续费、资金费、滑点和教学接管合计分别展示。采用 Maker 0.02% / Taker 0.05% 的公开训练基线；普通成交滑点为 0/2/10 bps 控制/默认/压力教学参数，详见实施计划。滑点只体现在成交价中，不再次扣款；接管合计不再叠加滑点。P0-B 已按教学模型确认关闭，官方精确清算费用仍为未知，不设零。已冻结到会话并在临时环境验证，尚未在正式服务启用。
- 每会话保留规则、数据和执行模型版本；恢复、复练、规则更新均不改写旧会话结果。若要用新版本练同一场景，另建有明确版本标识的会话。
- 提前结束有仓位时，默认先以平仓操作推进到下一可执行时点再结束；窗口到期的结束结算使用预留执行时点、单独标记「训练结束结算」，取消剩余委托后再揭晓，不能将结算误记为用户的交易判断。

以上产品默认已被确认，具体执行细化和规则参数仍以规则/实施文档标注的状态为准，不是已经测试通过的撮合规则。

### 强平与实盘差异必须可见

开局说明、下单/持仓风险区、强平结算详情和复盘均按[已确认教学结算规范](./2026-10-19-okx-liquidation-settlement-proposal.md)展示差异：本版全额接管且不返还，实盘可能部分减仓或返还余额；参考 mark 和手续费不等于实际清算成交与收费。穿仓缺口不追扣为教学约定，不能说成实盘赔付保证；缺口豁免不算交易盈利。说明直接可见，不新增每次开仓的重复确认弹窗。

## 第一版边界与投入

主要新增工作是合约订单/结算、保证金与强平、数据准入和恢复一致性，投入较大；会话、图表、盲评/揭晓、修正和首次/复练框架可复用，具体合约字段与行为需扩展核对。

暂不做：全仓、双向持仓、同会话多币组合、自动补保证金、同时支持多交易所、逐笔盘口重建、指数价触发和复杂自动订单、AI 教练、排行榜、对外用户交付、实盘账户连接。每项以后按明确训练用途单独决定，不作为首期的隐含前置。

独立加密分支现已完成 P1 纯计算、P2 BTC/ETH 两币小样及 P3a/P3b 市价与完整订单执行计算。原 P2 样本含 2024-01-01 至 01-04 的 72h 回放、此前 90 日背景和结束执行分钟；保持原样。P6 已另立两年历史池，2024–2025 两币普通/mark/资金费各 731 天通过核对，按周固定网格 210 个场景准入，0 缺口/排除。P4 已接训练会话和同一 SQLite 事务业务账本，验证只操作临时数据库；P5 界面操作已在临时服务验证，正式服务尚未启用。

## 验收条件与当前边界

以下是完整功能的验收条件；以下条件现已在冻结 BTC/ETH 小样上经过 P1–P5 分层验证；P6 两年数据池及冻结/首次隔离已验证，正式部署仍不在本轮范围：

1. 能在一个完整场景中开多/开空、加减仓、退出/强平、揭晓复盘，或全程不交易；原始判断可追溯。
2. 无自动止损的三种计划状态显示准确，手动计划不会偷偷成为自动订单；平仓和撤单语义明确。
3. 手动追加只改变资金分配，不重复计收入或增加仓位；资金费和恢复不重复记账。
4. 相同快照、规则与操作得到相同结果；标记价格和普通价格分离，分钟内歧义可见。
5. 多周期不泄露未来，批量推进和一分钟推进的最终状态一致；关键事件暂停后不暴露后续行情。
6. 首次与复练保留且分列，结束结算与策略退出分开；A 股现有行为和用户其他进行中工作不被合约改动破坏。
7. 教学接管完成 L01–L10/A08/A14：合计只结算一次、较高档位也按教学全平、不返还、无仓外追扣，四处差异展示可见，正式模型随会话冻结；不能仅凭用户接受方案标“功能验收通过”。
