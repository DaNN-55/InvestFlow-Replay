## 验证结果

- 后端全套 **172 passed / 0 failed**；新增训练分析HTTP/聚合8项与条件事件10项。额外核对日期非法输入、标签修正删除、收益与条件评估分母、前后样本不重叠、首次/复练、Demo、未揭晓、删除、只读、推进重试、T+1受限后成交保留事实。
- 前端单元全套 **196 passed / 0 failed**；覆盖空值与零、样本范围、北京时间日期、标签清空与原始快照保留。
- 浏览器全套 **52 passed / 0 failed**；新增真实临时账本分析分组/筛选/空状态/窄屏、事后标签追加→分析→样本跳转→评分不变、接口失败重试。已有订单、板块、复练对照、缓存面板继续通过。
- ESLint、生产构建与diff空白检查通过。
- 应用内浏览器核对了独立固定行情页面的对照入口和分析视图。正式5180页面也已实际打开：27次首次练习、26次已揭晓、1次进行中，26个收益/回撤样本，前后分组6次/20次。此处为用户当前本地记录读取结果，不是固定行情测试成绩。

页面验收未给正式练习下单、推进或交卷。标签写入仅发生于独立固定行情临时账本。临时3126/5196服务关闭并清理账本；正式本地服务使用项目原启动入口刷新，保持可访问。

## 使用入口与保留边界

“交易追踪 → 历史演练 → 首次分析 / 复练分析”。直接切换分析分组，用创建日期、周期、长度和板块缩小范围；修改筛选后点击“更新分析”。标签在揭晓后的事后复盘或追加修正中选择，分析会按当前有效版本汇总。

历史回算只使用原冻结计划和已有执行记录，不回写账本。旧记录未保存的受限过程无法完整还原，事件0只表示未找到证据。缺少问题标签不等于没有问题；不会根据亏损、空仓或旧文本自动推断。“拖延率”仍未实现，因为此前没有约定人工响应期限。本轮也未扩大到全市场历史、北交所、企业行动账户结算或画图持久化。

## 后续界面精简（2026-10-20）

按用户页面反馈，将两层“演练记录/训练分析”和“首次盲测/已知复练”合成一行“演练记录/首次分析/复练分析”，删去重复说明，压缩标题区域。首次与复练仍独立统计，来回切换不清空筛选、不重复请求报告。缓存面板的“板块样本覆盖”使用原生details默认折叠，点击或回车展开全部明细。

现有浏览器52项全部通过，覆盖键盘展开、窄屏、颜色、分析切换、筛选保留与请求次数；ESLint无告警，构建与diff检查通过。正式5180页面实际点击验证并保存截图replay-compact-controls.png，未改动正式练习数据。

随后按用户反馈，将首次/复练分析的日期、周期、长度、板块筛选、更新按钮及筛选说明并入上方切换卡片，三种视图复用ReplayHistoryControls。浏览器52项通过，补充确认两个分析分组的导航与筛选处于同一张卡片内；筛选保留与窄屏检查继续通过。实际页面截图：replay-analysis-filter-card.png。
