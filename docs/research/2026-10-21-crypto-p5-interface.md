## 设计约定

沿用 InvestFlow 的简洁训练工作台：图表为主、右侧执行，数字按 USDT/合约张数呈现；蓝色操作强调，风险用文字和颜色共同提示。共用已有 UiButton/Input/Select/Textarea 与 CandlestickChart，不修改股票训练器。全部计算和撮合继续在后端，前端估算只用于计划对照并明确排除成本/不保证成交。复盘以事实、自评和下次行动为主，不以盈亏给交易能力打分。

计划和事后自评属于训练记录，附着现有同一数据库与动作事务；不改 P1–P3b 执行版本或冻结行情。每次写请求先将 actionId/预期版本/完整意图保存到本地，网络结果不明时只允许原请求重试或核对服务端，避免重复操作。后端限制仍为 1/5/15 分钟与关键事件暂停。


## 实现结果

入口为主导航“合约盲测”，路径 `/decision/crypto-replay`。新增独立 Vue 工作台，复用已有图表与控件，不改股票撮合或股票训练组件。全量数据仍为 P2 冻结的 BTC/ETH 同窗小样，未下载或扩充数据池。

- 开局选择 BTC/ETH、起始资金、杠杆、0/2/10 bps；默认 10000 USDT / 5 倍 / 2 bps。固定 Maker/Taker 基线直接显示。
- 普通价与 mark 分别显示/选图，1min–1day 共 11 周期；服务端先按已知分钟截取再聚合，图表最多显示最近 600 根，1day 可观察完整 90 日背景。形成中 K 线明确标识；真实日期仅在揭晓后给出。
- 市价/限价开平、同向加仓、减仓、逐单撤销；支持开仓附带和持仓更新保护、last/mark 参考、单腿/全部取消，保护数量/OCO/部分退出均由原执行器决定。已处触发侧的止损价给出立即退出可能性的提示。
- 风险三态从实际保护单和已保存手动计划推导；M、mark 浮动盈亏、风险率、估算强平价与退出价分列。计划价格盈亏是排除成本和成交保证的展示估算；没有退出价时显示缺少比较基准。取消止损后恢复手动/无价状态，不自动平仓。
- 追加只划转可用资金与 M，不作为收入，不自动补充。开平/保护/追加理由及当时手动计划随动作保留；执行事件和精确资金桶账本可以展开核对。
- 完成退出 → 冻结首次盲评 → 揭晓 → 保存事后自评 → 按原版本复练可操作。事后自评保存观察、执行偏差、下次行动，保留原文，不套股票评分。首次与复练分列，揭晓后可对照同场景首份已完成/揭晓结果和资金/杠杆/滑点条件；原结果不改写。
- 浏览器发送前保存原 actionId/版本/请求。网络结果不明时锁定新操作，刷新后仍显示“重试原动作”；重试成功读取当前服务端状态，既不重复扣款也不退回旧游标。明确版本冲突后需重新同步和决定，不偷偷改版本重发。

后端增加的训练记录和事后复盘沿用同一 writer/事务；复盘同时更新既有不可变 post_json，历史状态能正确显示已复盘。新旧合约会话在没有训练记录时有明确空值默认。行情响应可选 limit，仅在因果聚合完成后截尾。架构记录见 [ADR-0012](../adr/0012-okx-training-interface.md)。

## 四处差异的实际落点

| 位置 | 实际呈现 |
| --- | --- |
| 开局 / 会话摘要 | 教学全额接管、不返还；实盘可能部分减仓或返还；固定训练费率、分钟/盘口/ADL 近似 |
| 下单与持仓风险区 | 强平阈值与退出价分列；追加也承担接管损失；仓外不自动补入；阈值不是保证成交价 |
| 接管详情 | 触发与撤单复核、M、合计、该动作后仓外可用；mark/费/W/S 为参考或教学拆分；实际成交/官方费用未知；不重复落账 |
| 复盘 / 恢复的历史详情 | “教学模拟结果，非 OKX 实盘清算账单”；净值包含接管；不向仓外追扣不是实盘赔付承诺，豁免不算交易盈利；完整版本/差异可展开 |

没有发生强平的会话也显示开局、风险区和复盘说明。发生接管后显示第四处详情；不需要先阅读研究文档或反复确认弹窗。

## 最终验证记录

以下为 2026-10-21 完成记录。

- P5 新增后端 **6 项**与前端 **5 项**针对性测试；后端全量 **273/273**、界面全量 **190/190** 通过，0 失败、0 跳过。事务失败回滚涵盖训练计划、理由、post_json/训练记录镜像；冻结自评和首次定位涵盖连续复练与另开同窗。
- 前端生产构建通过，变更文件 ESLint 通过。构建保留已有 Browserslist 数据较旧和依赖注释提示，不影响构建；未顺手升级依赖，web package/lock 没有改动。
- [真实浏览器验证脚本](../../backend/scripts/verify-crypto-interface.mjs)通过 **10 组**：BTC/ETH 多空 4 组、教学接管 2 组、止损/OCO 2 组、全程不交易 2 组。多头含限价等待/撤销、加减仓、保护设置/单腿取消/恢复、追加、跨资金费、刷新、首次/复练；空头走开平和两阶段复盘。另验证 A 股入口切换。
- BTC 追加场景中，测试让真实后端先完成事务，再丢弃 HTTP 响应；刷新后重试原请求，现金只减 500、M 只加 500。普通重试和浏览器快速操作另有控制器验证。
- 浏览器实测 1min/1day，读取下一未展示分钟得到 409；中间周期与分钟前缀的计算验证沿用 P2/P3。没有从客户端上传 state、规则或跳游标。
- 已检查实际开局、交易、移动端、复盘和两币接管截图；390px 无横向溢出，深/浅主题的当前交易页 axe WCAG 2A/2AA 自动检查均为 **0 violations**。这不等同于完整人工读屏审计。
- 浏览器 `pageerror` 为 0。测试使用真实冻结样本与本地后端、临时数据库，不 mock 行情/撮合/账本；不运行 TDX 行情交易。A 股兼容由本分支 legacy 的后端与前端回归及入口浏览器检查覆盖，原目录尚未合入的新股票执行模型仍待整合后另验。
