# ADR-0008：行情样本保存完整证据，可见数据只按时间前缀生成

## Status

Accepted（P2 实施约束），2026-10-19。用户授权独立加密分支准备行情和验证无未来泄露；不接界面、会话或账本。

## Decision

在本地文件中保存同源 OKX 普通 1m、mark 1m、资金费原始事件及 hash 证据。普通/mark 全部使用 REST 的已完成记录，资金费使用官方长期归档；UTC 毫秒保存源时刻，北京时间定义场景和日线边界。资料缺口拒绝准入，不前向填造 OHLC 或资金费。

原始及规范化全量数据属于内部材料；对外投影先按游标截取已完成分钟，再聚合 1m–1d，当前较大周期仅含已知分钟。最终资金费率仅在其原始事件时间不晚于游标时输出；盲测视图使用相对时间，不返回真实日期、全量 manifest 或源 URL。规则与数据版本分开，已冻结样本不静默换源。

该方案让历史文件能离线复核，也避免提前拿到日/小时最终高低收或尚未发生的费率。代价是首期仅有分钟观察精度，不能声称恢复秒级资金费发布时延或盘中价格路径。资金费归档可能有秒级偏移，保留实际值，不强行对齐整点。

## Validation

完整性拒绝测试、普通/mark 时间对齐、官方粗周期对账、资金费前后事件、篡改文件 hash 拒绝，以及未来数据/最终费率扰动不影响已知前缀的测试。完整服务端隔离仍待 P4，不能凭离线投影测试宣称已经完成接口防泄露。
