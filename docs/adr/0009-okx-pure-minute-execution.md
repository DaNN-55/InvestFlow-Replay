# ADR-0009：合约分钟执行保持独立纯状态转换

## Status

Accepted（P3a 实施约束），2026-10-20。用户授权在加密分支实现市价开平、资金费、风险检查、手动追加和教学接管；不接界面或业务账本。

2026-10-20 P3b 更新：完整纯订单执行已有独立新版本，36 项测试及真实 BTC/ETH 验证通过；原 P3a 数值保持不变，尚未接业务或 UI。见[ADR-0010](./0010-okx-orders-and-protection.md)和[P3b 报告](../research/2026-10-20-crypto-p3b-orders.md)。

2026-10-20 P4 更新：已接同一 SQLite 会话/业务账本事务、幂等、恢复、冻结复练及服务端游标；新增 17 项、后端全量 267 项和真实两币对账通过。仅临时数据库验证，界面未接、正式服务未启用。此前“待 P4”为对应阶段的历史状态；当前范围见 [ADR-0011](./0011-okx-session-transactions.md)和[P4 报告](../research/2026-10-20-crypto-p4-sessions.md)。


## Decision

新增独立的 `replay-crypto-execution.js`，显式注入冻结规则与已验证场景，复用 P1 金额计算及 P2 资金费 mark 代理。对外只有创建初态与执行命令；输入/输出为 JSON 值，每次转换返回新状态和本次计算轨迹。该轨迹不写数据库，不建立另一套业务账本；P4 再由现有事务入口统一持久化、校验 actionId/revision 和服务端游标。

游标代表已完整展示的分钟。市价委托在提交时用最近已完成普通分钟估算并预留开仓保证金＋费用，推进后在第一个未展示分钟开盘执行；成交时释放预留并按实际模拟价复核资金。开平都受合约市价上限约束；P3a 对分钟普通张数不足的委托整笔拒绝，无成交则无手续费，部分成交及同向加仓留给 P3b。容量采用完整执行分钟的普通成交张数，直到该分钟结束才可核对，是有显式标识的分钟模型近似，不代表开盘已知盘口。平仓仅减仓，可全部或部分退出，不跨零反向；正反方向需先平再开。不设止损不影响市价开仓许可。

每分钟先处理已到边界的资金费与风险，再处理该分钟 mark 开盘缺口、用户市价单和成交后风险；已知开盘不能排在后来的资金费或盘中极值之后。分钟内部仅凭 OHLC 无法确定极值与秒级资金费先后时，分别模拟「内部资金费→不利 mark 极值」和「不利 mark 极值→内部资金费」两种教学路径（各路径资金费自身按原始时间排序），完成已知的收盘及边界资金费后，选收盘账户权益较低的一条；同值优先资金费在前。记录两路径结果与歧义，不宣称穷尽真实秒级路径。单纯盘中 mark 极值触发也标明只有区间、没有精确触发秒数。资金费仍按源时刻及事件前已完成分钟的 mark close 代理，不按整点改写或取未来 close；其对持仓资格的含义是训练约定，不声称恢复实盘结算冻结与发布时延。

风险触发后由执行器清理自己的待执行委托、释放冻结，重新检查，再调用 `isolated-full-loss-teaching-v1` 全额接管。只有 aggregateSettlementPnl 计入接管合计；参考 PnL/费用/核销/豁免为非记账解释，不再扣费，不动仓外现金。资金费先从 M 收付并立即检查，允许其造成负保证金后教学豁免；该豁免不计为交易盈利。正常主动平仓的数学现金缺口单列，绝不静默套用强平豁免。

手动追加在当前已展示边界立即划转，仅改变可用与 M；已经在上一个完成分钟触发的接管不可被事后追加撤销。批量推进复用逐分钟函数；默认遇成交、已持仓资金费、拒单或强平后在该分钟结束暂停，不计算或暴露后续分钟。窗口结束只用预留分钟的开盘退出，先风险处理再结束平仓、撤余单；退出容量不足则明确记录结束受阻并保持未平仓状态，不捏造超过成交量的普通成交或新增非风险接管触发条件；完整结束异常流程留给 P3b。

## Consequences

没有网络、文件、时钟、随机数、HTTP 或数据库依赖。冻结输入与操作得到相同结果，批量与逐分钟可直接比较。冻结数据和输入状态为可信内部值，状态含版本信息，不能直接作为盲测 HTTP 响应；本接口不提供客户端授权或持久化幂等保证。限价、自动保护、部分撮合、同向加仓及完整结束异常流程仍待 P3b；UI 展示验收待 P5。

## Validation

| 成功条件 | 对应验证 |
| --- | --- |
| 市价无回填、多空/减仓/资金校验、预留释放 | 人工独立算例、跳空、余额和成交量不足、超量退出拒绝 |
| 资金费只对当时持仓收付且只处理一次 | 边界/秒差/同分钟开平、正负率多空、重复游标拒绝或无重复处理 |
| mark 风险与 last 成交分离，已知开盘先于盘中 | 多空缺口、恰好阈值、开盘平仓避开后来极值、两条歧义路径 |
| 追加守恒与教学接管单次合计 | P1 金标及负保证金/缺口/仓外保护、撤单后复核 |
| 批量一致、暂停不暴露未来 | 1/5/15 分钟与整段推进比较，未来 OHLCV/费率扰动，输入输出隔离 |
| 冻结真实小样闭环 | BTC/ETH 多空、跨资金费、追加、结束、不交易和高杠杆风险；核对 manifest/文件 hash |
| 边界不扩散 | 新计算模块依赖检查，不改 UI/HTTP/事务/数据库和原 A 股目录 |
