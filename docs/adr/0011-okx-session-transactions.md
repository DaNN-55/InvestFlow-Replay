# ADR-0011：合约会话沿用同一 SQLite 事务并冻结全部执行输入

## Status

Accepted（P4 实施约束已实现），2026-10-20。用户授权会话/业务账本、动作幂等、恢复、复练版本和服务端可见游标；暂不接界面。

## Decision

通过现有 `createDatabase`、Replay store 和 interaction/HTTP 边界接入 crypto-perpetual 市场；不创建另一份账户数据库，不挪用股票整股/REAL 成交字段。新增的合约持久化 adapter 只使用 createDatabase 的同一个连接和事务，业务状态只经该 facade 写入。

- replay_sessions 添加市场、执行版本及冻结/状态校验值，旧行默认 ashare / legacy-next-open。合约内部执行状态存入现有 account_json；市场与执行版本决定解释方式，禁止走股票执行或评分路径。原目录并行未提交的 bar-orders/board-orders 实现不自动合并，未知 A 股执行版本不回落为旧模型执行。
- 全量普通/mark/funding、规则和执行版本存为不可变、按内容 hash 寻址的共享冻结文档，留在同一 SQLite。会话 descriptor 只引用该文档并冻结起始金额、杠杆和滑点；复练复制 descriptor/config，不重新下载、不读当前全局规则。重启先验 hash，缺失/不支持/损坏显式报错，不静默降级。相同历史窗口的尝试共用场景身份，首次与复练分别记录。
- 每个写动作在 BEGIN IMMEDIATE 内先匹配 actionId 与规范化请求，再比较 expectedRevision，再由已持久化的状态计算。重复同请求返回该次提交的状态/游标，改用同 ID 的不同动作拒绝；旧 revision 拒绝。状态、游标、轨迹、现金桶账本和动作结果原子提交，任何异常整体回滚。创建和复练也有动作 ID，重试不重复创建或消耗尝试编号。
- 合约账本每动作一行，以十进制 TEXT 保存 available/reserved/M 的实际变化，以及手续费、资金费、价格收益、接管合计和追加的变化；逐事件成交/资金费/接管细节单独保存为有序轨迹。账本记录只反映状态转换，解释性的参考费用/核销/豁免不另记收费。没有把股票 REAL 字段当作精确 USDT，也不将轨迹与桶变动重复相加。
- 所有可见行情/轨迹均由服务端会话当前已展示游标限定。客户端不能上传执行状态、规则、版本、snapshot 或直接指定推进后的游标；只接受 1/5/15 分钟推进，并保留事件暂停。读取过去游标可以，未揭晓前读取未来拒绝；先截完整分钟，再聚合周期。公开会话不返回源文件、真实行情日期、数据版本中的日期或完整冻结文档。
- 结束和揭晓分开；ending 和 end-blocked 保留仓位/订单风险状态，不能当作已完成。首份盲评冻结后，只有 completed 且空仓才可揭晓；复练以已揭晓源会话的冻结输入创建独立初态，原结果不改写。复盘 UI/评分扩展留给 P5，不能套股票评分计算。

## Success conditions

| 可检查结果 | 验证 |
| --- | --- |
| 创建/下单/资金费/追加/接管/结束重试只提交一次 | 临时 SQLite 的 actionId、revision、账本/轨迹唯一约束与响应游标断言 |
| 同 ID 改请求、旧 revision、客户端跳游标拒绝 | HTTP 和直接 facade 负例，状态与现金不变 |
| 中途 SQL 异常不留下半套数据 | 人为失败的 ledger INSERT 触发器；账户/revision/轨迹/动作/尝试编号回滚 |
| 重启恢复活动单/保护、费用和游标 | 关闭重开同一临时 DB；使用持久冻结文档，不依赖当前源文件 |
| 复练保留数据/规则/执行/费用/资金预设 | 修改或禁用当前 source 后复练；旧结果和 descriptor 保持相同，初态独立 |
| 冻结实际 BTC/ETH 可由事务重放 | 原始规范化 hash、资金费/追加/退出或接管后账本 Decimal 汇总一致 |
| 旧 A 股不被合约改变解释 | 本分支 legacy 会话/交易/生命周期/历史/复练回归；原目录新模型只读检查、未知版本拒绝执行 |
| 不接 UI 或正式账本 | 仅临时数据库验证；不启动正式服务，不修改 web |

## 实施结果

17 项新增测试、后端全量 267 项与冻结 BTC/ETH 事务对账通过。仅本分支 legacy A 股兼容已验证；原目录未合入的新模型须未来另验。详见[P4 实现与验收报告](../research/2026-10-20-crypto-p4-sessions.md)。

2026-10-21 P5 补充：已接合约界面和两阶段自评，训练计划/理由与 post_json 镜像仍在本 ADR 同一事务内；P4 中“暂不接界面”是当时阶段边界。当前见 [ADR-0012](./0012-okx-training-interface.md)与[P5 报告](../research/2026-10-21-crypto-p5-interface.md)。
