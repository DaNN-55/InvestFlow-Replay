# ADR-0004：按板块和历史日期冻结 A 股训练规则

## Status

Accepted，2026-10-19。用户授权实现主板、创业板、科创板规则修正。

## Decision

- 新会话使用 `bar-orders-v2`；已有 `bar-orders-v1` 和 `legacy-next-open` 不升级，复练继承原版本。订单生命周期与账户事务不另建。
- 此处新模型范围为用户使用的日线和hybrid 5分钟；未提供可靠日参考价的旧纯1分钟入口继续使用 `bar-orders-v1`。
- 现有离线Demo合成证券继续使用原模型，必须同时匹配Demo交易所、合成代码和fixture因子来源；不会把合成证券或北交所误识别为沪深A股。
- `replay-board-rules.js` 集中处理板块识别、申报数量、比例取整、单笔数量上限和涨跌停判定；界面只接收板块名称和数量约束，不泄露代码、名称、日期或未来价格。
- 主板、创业板买入100股整数倍；科创板200股起逐股递增。卖出支持一次性处理零股；申报数量约束与逐笔成交数量分开，合法订单允许按股部分成交，不能留下永远无法卖出的尾数。
- 以历史日期应用创业板2020-08-24前10%、之后20%，科创板20%、主板普通股10%。参考价使用当日未复权前收盘参考价，先按原始0.01元价格档位计算边界，再转换到会话复权坐标。5分钟bar不得使用上一分钟收盘价作为日涨跌幅基准。
- 优先使用冻结的明确涨跌停数据。源数据缺少完整历史ST、重新上市等特殊状态，不把当前名称当作历史状态；历史5%边界、超出普通幅度、缺失可靠日参考价或明确未知的窗口返回规则信息不足，停止该bar撮合并展示原因，不归为用户违规。不重建完整历史制度库。
- 本批不模拟盘口、连续竞价价格笼子、临时停牌或盘后撮合；保留已有bar容量近似和T+1。北交所和非A股不能进入新板块模型。

## Validation

覆盖三板块合法/非法数量、比例预算、零股卖出、按股部分成交、单笔上限、真实涨跌停与非涨停一价行情、历史制度日期、除权复权和跨5分钟日基准、未知状态、刷新/复练版本隔离以及匿名投影。

规则依据及验证结果另见本批实现记录。

2026-10-21提交前检查补充：新申报的数量上限使用下一根首次可参与撮合bar的交易日，界面校验与执行日期一致；跨越创业板2020-08-24切换日的回归覆盖前后两种上限。
