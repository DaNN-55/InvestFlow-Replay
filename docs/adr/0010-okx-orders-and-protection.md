# ADR-0010：完整合约订单使用独立执行版本和共享分钟容量

## Status

Accepted（P3b 实施约束），2026-10-20。用户授权同向加仓、限价、部分撮合、止盈止损、撤单和保护联动，以冻结 BTC/ETH 小样验证；不接界面或业务账本。

2026-10-20 P4 更新：已接同一 SQLite 会话/业务账本事务、幂等、恢复、冻结复练及服务端游标；新增 17 项、后端全量 267 项和真实两币对账通过。仅临时数据库验证，界面未接、正式服务未启用。此前“待 P4”为对应阶段的历史状态；当前范围见 [ADR-0011](./0011-okx-session-transactions.md)和[P4 报告](../research/2026-10-20-crypto-p4-sessions.md)。


## Decision

新增独立纯执行版本 `okx-orders-minute-teaching-v1`，保留 P3a 的 `okx-market-minute-teaching-v1` 及其原始结果。复用 P1 规格/费用/保证金/风险/接管和 P2 场景校验，接口仍为 create/apply 的 JSON 状态转换与增量计算轨迹，无 I/O 或业务写入。此状态是可信内部材料，不直接作为盲测响应。

- 同向加仓增加本次成交初始保证金，不重置旧 M；按合计持仓核对档位和杠杆。新增 `entryNotional` 金额成本基准，完整与部分退出均以该基准核算，避免循环小数均价破坏资金守恒；均价只作展示。该扩展不改变没有此字段的 P1/P3a 计算行为。
- 多个活动单按提交 ID 排序；当分钟普通成交张数按 lot 向下取整后共享。市价 IOC 部分成交后撤余；限价 GTC 保留余量和预留，若实际资金不能覆盖剩余预留，明确撤余。成交容量是完整分钟的教学近似，不是开盘已知盘口或真实参与率。
- 首次可执行开盘即满足买入 open<=limit / 卖出 open>=limit 时按 taker 加滑点，不突破限价；滑点越价保持未成交，当分钟不再伪装 maker。首次未能立即成交的等待单，买需 low<=limit−tick / 卖需 high>=limit+tick；按限价 maker 成交，无额外滑点。用户限价和保护价必须符合各自合约 tick。
- 平仓仅减仓，不能跨零。手动退出单总余量不超过实际仓位；仓位变化时按 ID 裁剪超额退出余量。全部退出清理旧仓的活动单及保护，不能以后意外重新开仓。反向必须先完成平仓。
- 可在开仓/加仓单附带保护，也可持仓后设置；保护覆盖该仓全部实际张数，默认 last，可各腿选 mark。加仓扩大，减仓缩小；一腿触发立即撤另一腿及旧仓的普通活动单。保护退出按 taker 使用同分钟剩余容量，部分/零成交的剩余数量在后续分钟开盘继续作为市价退出；取消保护不平仓，也不恢复已取消另一腿。
- 已知 mark 开盘风险先于用户开盘成交，已触发保护的余量/已在开盘满足的保护也在开盘处理，不能拿后来极值撤销已完成退出。盘中 last 触发采用触发价加方向滑点；mark 触发因缺同步普通报价，采用该分钟普通价不利极值加滑点，明确近似；开盘触发均用普通 open。触发价不是保证成交价。
- 分钟内对可达的 mark 风险、止损、止盈、等待限价和内部资金费阶段枚举教学先后（同阶段订单按 ID、资金费按源时刻），保留已知开盘和结束边界先后。完成分钟后取权益最低路径，同值按固定 risk/SL/TP/limit/funding 顺序。记录候选权益与未知真实路径；这不是穷尽真实逐笔价格路径或排队。事件无容量不虚构 fill，不收费。
- 资金费仍保留原始时间，使用事件前已完成分钟 mark 代理，之后立即重算风险。风险先撤全部活动单及保护、释放预留再复核，仍危险才按已确认教学全额接管；参考费用不重复扣、仓外不追扣，不新增非风险强平。
- `finish` 撤活动单和保护；有仓位从下一未展示分钟 open 尝试退出，不足容量可分分钟继续，至预留分钟后仍未平则 end-blocked。无仓位可直接结束；到期同样先撤单/保护、再风险与结束退出，不越过冻结窗口或伪造缺口行情。

## Success conditions and validation

| 可检查结果 | 对应产出 |
| --- | --- |
| 同向加仓的加权成本、M 与合计档位正确且守恒 | P1 可选成本基准与 addPosition；独立非整除均价及跨档算例 |
| taker/maker、严格穿价、限价边界和部分费正确 | 人工金标与真实 BTC/ETH 限价；共享容量、取消余量和冻结释放 |
| 保护数量/OCO、部分保护余量、撤单不复活 | 附带/设置/取消保护、加减仓、全平、强平、零容量、多腿触发测试 |
| 已知开盘不倒序，分钟歧义保守且有证据 | 开盘先退出、mark/last 分流、SL/TP/强平/限价/资金费组合 |
| 无未来与批量一致 | 人工/真实小样 1/5/15/整段状态和轨迹相同、未来价格/率扰动 |
| 结束不虚构成交或新接管条件 | 提前结束、部分退出、到期撤单及 end-blocked |
| 边界不扩散 | P1/P2/P3a 回归、冻结文件 hash，无 UI/HTTP/数据库改动 |

## Consequences

新版本可解释地承载教学撮合，不冒充 OKX 逐笔实盘；旧执行版本不自动升级。所有复练、恢复、幂等、事务与服务端揭示权限仍待 P4；界面和四处实盘差异呈现待 P5。当前没有创建真实订单或业务会话。
