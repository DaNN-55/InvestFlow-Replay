# ADR-0012：合约界面复用现有图表与事务，训练记录独立于执行版本

## Status

Accepted（P5 约束已实现），2026-10-21。用户授权训练界面、复盘、风险三态、保护单、手动追加与四处实盘差异；暂不扩大数据池。

## Decision

- 在现有导航增加 `/decision/crypto-replay`。复用 Vue、UiButton/Input/Select/Textarea、CandlestickChart 与同一后端，不向股票训练器注入合约仓位字段，不新增框架或数据服务。
- 合约界面的所有撮合/金额变化仍由 P4 同一 SQLite 事务入口提交。前端只展示服务端风险和金额；计划价格盈亏仅作未含成本的展示估算，不落账。P1–P3b 数学/执行版本和行情保持不变。
- 当前手动计划和逐动作理由存入 `replay_crypto_journals`，与动作/账户/轨迹/精确账本同一事务。首次盲评沿用 replay_reviews，事后自评同时写入既有不可变 post_json 和训练记录；两者原子提交，历史状态能识别已复盘，股票评分逻辑不参与。
- 风险三态由实际保护单优先决定：活动止损为自动；否则已记录手动价为手动；其余未设退出价。手动价不会生成订单；取消止损不等于平仓，止盈仍独立显示。没有退出价不显示零损失估算。
- 控制器在发送前把 actionId/预期版本/完整请求存入专用 localStorage，只保留引用和待核对动作。结果不明时锁定新动作，刷新后仍可重试相同请求。成功后读取最新服务端状态，避免幂等旧响应令页面退回旧游标。明确 4xx 后由用户同步并重新决定，不自动换 revision 重发。
- 行情仅经 P4 服务端游标接口读取；可选 limit 在因果前缀聚合后截尾，不降低原有校验。1min–1day 均可选，形成中 K 线只含已知部分；显示相对时间，揭晓后才给实际日期。
- 首次与复练按同一场景身份查首个已完成/揭晓结果，不沿来源链误将最近复练称为首次；子会话揭晓后才能对照。不同起始资金/杠杆/滑点明确展示，已见行情不混入首次成绩。
- 开局、持仓风险区、教学接管详情与复盘都直接显示教学差异。接管按合计一次落账，参考 mark/费/W/S 为非入账解释；实际成交和官方费用未知，缺口豁免不当盈利或实盘赔付。

## Validation

[P5 成功条件、实施与验收](../research/2026-10-21-crypto-p5-interface.md)。覆盖事务失败、刷新/丢响应、冻结自评、首次比较、两币多空/不交易/保护/追加/接管/复练的真实浏览器流程。验收使用临时数据库及固定 BTC/ETH 小样；正式数据库和数据池保持原状。
